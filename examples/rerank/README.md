# Re-ranking Example

Turns a rare-variant burden result into a calibrated, auditable per-gene table with
`hvantk rerank`, using small synthetic fixtures so the whole thing runs in a few seconds
without Hail, a cohort, or network access.

## Contents

```
examples/rerank/
├── config.yaml          the run: cohort + two evidence axes + labels
├── make_fixtures.py     regenerates data/ (seeded; rewrites the same bytes)
├── data/
│   ├── cohort.yaml       the cohort manifest -- prior column + architecture axis
│   ├── cohort.tsv        gene, minp, n_case_var, conc, driver_af -- prior + audit architecture
│   ├── constraint.tsv    gene, mis_z, pli    -- evidence axis 1 (ablation baseline)
│   ├── expression.tsv    gene, dev_expr      -- evidence axis 2
│   └── labels.txt        40 positive genes   -- external training label
└── results/
    └── rerank_scores.tsv   committed reference output (150 genes)
```

## Quick Start

`scikit-learn` is an optional dependency, so install the `ml` extra. Run from the
**repository root** — paths inside `config.yaml` are resolved against the working
directory, not against the config file.

```bash
poetry install --extras ml
eval "$(poetry env activate)"

hvantk rerank -c examples/rerank/config.yaml -o /tmp/rerank_scores.tsv

# Compare against the committed reference
diff /tmp/rerank_scores.tsv examples/rerank/results/rerank_scores.tsv
```

## Test Data

Entirely synthetic and generated by `make_fixtures.py` (`numpy.default_rng(0)`): 150
genes, 40 of them positive. Both feature axes carry real signal about the label, with
expression slightly weaker than constraint so the drop-one ablation produces a non-trivial
ordering rather than two identical rows.

The cohort table (`data/cohort.tsv`, declared by `data/cohort.yaml`) carries both the
prior statistic (`minp`) and the case/control architecture columns in one place -- a
cohort manifest can only point at a single gene-level table. It deliberately seeds every
branch of the advisory audit, so the flag columns in the output are non-empty: 4 genes
with `n_case_var <= 2` (`insufficient_data`), 4 with `conc >= 0.6` and elevated
`driver_af` (`recurrent_variant`), and 3 with `driver_af > 1e-3` (`common_driver`).

**These numbers are a smoke test, not a scientific result.** The data is invented; do not
read the AUCs as evidence of anything.

## Expected Outputs

`rerank_scores.tsv`, one row per gene, with columns `gene`, `prior_stat`, `score`,
`score_percentile`, `tier`, `verdict`, `flag`, `flag_reason`, `y`. On the shipped
fixtures the run prints:

```
Wrote 150 genes -> ...
Credibility: ROBUST=60 / INTERMEDIATE=90 (over 150 scored genes)
Audit: 11 gene(s) FLAGGED for review (advisory; ranking not overridden).
       Reasons: {'insufficient_data': 4, 'recurrent_variant': 4, 'common_driver': 3}
Per-axis ablation (delta-AUC over constraint):
    family   auc   d_lo  d_md  d_hi
constraint 0.846  0.000 0.000 0.000
expression 0.864 -0.022 0.018 0.066
```

The audit is **advisory**: flagged genes keep their score and their place in the ranking.
The ablation CI for expression spans zero, which is the honest outcome for a small
synthetic set — a real axis would need a real cohort to earn a claim.

## Reproducibility

Every stochastic step is seeded (`random_state=42` for the classifier, the cross-validation
split, and the bootstrap). On a fixed dependency set the output is byte-identical, and it
was verified unchanged between `OMP_NUM_THREADS=1` and `OMP_NUM_THREADS=4`, so thread
count does not perturb it here.

Across **scikit-learn versions** the last decimal places may move, and a gene sitting
exactly on a tier boundary can shift one tier. The committed reference was generated with
the versions in `environment.yml` (scikit-learn 1.7.2). Treat `score` as reproducible to
about `1e-6` rather than byte-identical, and compare rankings rather than raw floats when
checking across environments.

To regenerate the fixtures and the reference output together:

```bash
python examples/rerank/make_fixtures.py
hvantk rerank -c examples/rerank/config.yaml -o examples/rerank/results/rerank_scores.tsv
```
