# Examples

Tutorials and walkthroughs for hvantk tools and workflows. Each page covers concepts, CLI and Python API usage, and expected outputs.

Runnable scripts are available in the [`examples/`](https://github.com/bigbio/hvantk/tree/main/examples) directory on GitHub.

## Tools

| Example | Description |
|---------|-------------|
| [HGC](hgc.md) | Joint genotyping QC and scalability benchmarks |
| [EnrichEx](enrichex.md) | Gene set overlap enrichment and burden testing |
| [PS-ROC](psroc.md) | Pathogenicity score ROC evaluation |
| [Ancestry](ancestry.md) | Ancestry inference with PCA + Random Forest |
| [QTL Cascade](qtlcascade.md) | Molecular QTL integration (eQTL + pQTL) |
| [PTM](ptm.md) | Post-translational modification site analysis |

## Runnable examples in the repository

These ship with fixtures and a `README.md` you can follow end to end. They live under
[`examples/`](https://github.com/bigbio/hvantk/tree/main/examples) rather than on this
site because each one is a directory of scripts and data, not a page.

| Example | What it runs | Needs |
|---------|--------------|-------|
| [rerank](https://github.com/bigbio/hvantk/tree/main/examples/rerank) | `hvantk rerank` end to end on synthetic fixtures — cohort manifest, two evidence axes, external labels, committed reference output | `--extras ml`; no Hail, no network |
| [1k_genome](https://github.com/bigbio/hvantk/tree/main/examples/1k_genome) | Building a Hail MatrixTable from 1000 Genomes NYGC high-coverage data, for use as an ancestry reference panel | Hail; large download |
| [enrichex](https://github.com/bigbio/hvantk/tree/main/examples/enrichex) | Overlap enrichment, burden analysis, synthetic-cohort demo, plotting and reporting | `--extras enrichex` |
| [hgc](https://github.com/bigbio/hvantk/tree/main/examples/hgc) | Joint-genotyping QC plus CPU-scaling and scalability benchmarks | Hail |
| [ancestry](https://github.com/bigbio/hvantk/tree/main/examples/ancestry) | Basic inference, a custom reference panel, and a full run script | `--extras ancestry` |
| [psroc](https://github.com/bigbio/hvantk/tree/main/examples/psroc) | Pathogenicity-score ROC evaluation | `--extras psroc` |
| [clinvar](https://github.com/bigbio/hvantk/tree/main/examples/clinvar) / [clingen](https://github.com/bigbio/hvantk/tree/main/examples/clingen) | Streamer usage and ontology categorization against real data | Hail |

`rerank` is the quickest way to see the multi-omic re-ranking workflow without a real
cohort — the fixtures are synthetic, seeded, and regenerated by `make_fixtures.py`.
