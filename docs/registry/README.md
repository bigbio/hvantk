# Dataset Registry

This directory contains the dataset registry and validation status viewer for hvantk.

## Contents

- **index.html** - Web interface for browsing dataset registry and validation status
- **styles.css** - Styling for the registry viewer

## Purpose

The registry provides:
- Visual dashboard of available datasets
- Validation status for Hail MatrixTable compatibility
- Dataset metadata and statistics
- Last update timestamps

## Viewing the Registry

Open `index.html` in a web browser to view the dataset registry dashboard.
